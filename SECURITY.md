# Security

Please report a vulnerability through [GitHub’s private vulnerability reporting form](https://github.com/augarte/BreezePilot/security/advisories/new). Include the affected version or commit, a description of the impact, and steps to reproduce it with dummy credentials. Keep real device tokens, credentials, and private network details out of reports.

Use [GitHub Issues](https://github.com/augarte/BreezePilot/issues) for regular bugs and compatibility reports.
